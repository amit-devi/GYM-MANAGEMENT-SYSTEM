# 🏋️ My Fitness - Gym Management System

A lightweight, modern web-based Gym Management System offering role-based portals for both gym administrators and members. It features automated billing logs, subscription plan upgrades, trainer assignment, workout scheduling, and an interactive AI help assistant.

## 📌 Summary
The **My Fitness** system is an all-in-one Single Page Application (SPA) designed to streamline health club operations. Built with pure HTML5, Tailwind CSS, and Vanilla JavaScript, the app operates entirely in the browser with `localStorage` persistence, making it fast, zero-dependency, and instantly testable without setting up a backend server.

---

## ✨ Features

- **🔐 Dual Role Authentication:** Pre-configured access for Administrators and Members, plus member self-registration.
- **📊 Admin Dashboard:** Real-time visibility into total member counts, gross revenue, member records, and payment history.
- **💳 Membership Management:** Browse and subscribe to tiered gym packages (`Basic`, `Pro`, and `Elite`).
- **🏋️ Trainer Profiles & Assignment:** View coach specialties, ratings, and assign dedicated trainers to member profiles.
- **📅 Weekly Class Schedules:** Dynamic workout timetables with class durations, instructor assignments, and booking alerts.
- **🤖 Built-in AI Assistant:** Floating chatbot widget to answer FAQs regarding branch hours, membership pricing, and demo logins.
- **🗄 Relational SQL Exporter:** Built-in modal to copy pre-structured MySQL database schemas for full-stack migration.

## ⚠️ Disclaimer
> **Educational & Demonstration Notice:**  
> This project is developed primarily for educational, demonstration, and portfolio purposes. The authentication, financial tracking, and data storage utilize client-side browser storage (`localStorage`) and standard JavaScript logic. For production deployment in a commercial fitness facility, implement a secure server-side backend (such as Node.js, Python, or PHP), encrypted password hashing (e.g., bcrypt), and an authenticated payment gateway (e.g., Stripe, Razorpay, or PayPal).
